# 개발 세트 실험 기록

설계 값(k, m, 출력 상한)을 정하거나 조건부 부품의 채택 여부를 정할 때, 그 근거를 여기 남깁니다. 11/27 채택 확정과 최종 보고서의 "왜 이 값인가" 절이 이 기록을 근거로 합니다.

- 모든 실험은 **개발 세트**에서 합니다. 평가 세트는 쓰지 않습니다.
- 파일 이름: `YYYY-MM-DD-<담당>-<주제>.md` — 예: `2026-11-14-b-retrieval-k.md`
- [TEMPLATE.md](TEMPLATE.md)를 복사해서 씁니다.
