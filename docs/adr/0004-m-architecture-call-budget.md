# M은 라우터 + 근거 판정 루프의 단일 에이전트, 호출 예산은 문항당 4회

M은 첫 호출의 라우터가 수학 풀이 / 검색 경로를 고르고, 검색 경로에서는 답 생성과 같은 호출 안에서 근거 판정(ANSWER · RETRIEVE · ABSTAIN)을 하는 LangGraph 단일 에이전트다. 가장 긴 경로(라우터 1 + 판정 1 + 재검색 후 판정 2)에 맞춰 호출 예산을 모든 문항에 4회로 둔다. 판정을 별도 호출로 두지 않고 답과 합친 것은 호출 수를 P1 이하로 묶기 위해서다.

## Considered Options

- **직답 경로(검색 없이 지식으로 답)**: 평가 세트에 검색 없이 답하는 것이 정상인 유형이 없고, 7B가 기억에 기대면 환각 오답과 기권 실패가 늘어난다. 2차 교차검증 후 제거했다.
- **멀티 에이전트**: 역할마다 호출이 늘어 파레토 개선 목표와 어긋난다.
- **유형별 호출 상한**: 에이전트가 유형을 모르므로 적용할 수 없다. 유형별 목표 호출 수는 분석용 기준으로만 쓴다.
- **잘림 재시도를 예산에 포함**: 정상 경로가 예산 소진으로 끝난다. 재시도는 예산에서 빼고 비용 지표에는 넣는다.

## Consequences

- 재검색은 최대 2회이고, 마지막 판정은 RETRIEVE를 낼 수 없다.
- 예산 소진은 기권과 따로 집계한다.
- 근거 판정 출력은 자유 서술(1~2문장)을 맨 앞에 둔 JSON이다. 답 키가 서술보다 먼저 생성되면 GSM8K 정확도가 29.87%까지 떨어졌다(Let Me Speak Freely).
- 단계별 출력 상한: 첫 호출 512, 계산기 후 마무리 128, 근거 판정 + 답 256 (num_predict 하드 상한).
