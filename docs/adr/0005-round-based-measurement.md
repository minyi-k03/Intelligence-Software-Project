# 측정은 묶음별 라운드로: 본 비교 3라운드, 절제 1라운드, 서로 다른 세션

Colab 무료 노트북은 최대 12시간이고 사용 한도가 수시로 바뀌므로(Colab FAQ), 모든 파이프라인을 한 세션에 돌리지 않고 본 비교 묶음(P0 · P0-raw · P1 · M)과 절제 묶음(M + 절제 변형)을 다른 세션에서 측정한다. 본 비교는 시간 변동을 보기 위해 3라운드, 절제는 temperature 0이라 정확도가 거의 같으므로 1라운드로 시작한다. 추정 합계는 5.3~11.1시간이며 1주차 10문항 실측으로 확정한다.

## Consequences

- 라운드마다 실행 순서를 바꿔 순서 효과(캐시, 발열)를 줄인다.
- 절제 변형의 시간·호출 수는 같은 묶음 안의 M 대비 비율로 보고하고, 보고서에 "절제 변형은 1라운드 측정"이라고 명시한다.
- 시간이 남으면 기여가 큰 부품의 절제 변형부터 라운드를 늘린다.
- 문항마다 즉시 저장하고 이어 돌 수 있어야 한다.
