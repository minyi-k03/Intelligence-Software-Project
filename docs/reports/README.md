## 발표 흐름 (초안)

1. 문제: 같은 모델로 더 정확하고 더 싸게 — 하네스만 바꾼다
2. 설계 한 장: 입력 쪽(근거) + 출력 쪽(예산)
3. 처리 흐름과 부품
4. 공정한 비교를 어떻게 보장했나 (P0 / P0-raw / P1, 동결, 같은 도구·지시문)
5. 결과: 보고 문장 + 본 비교표
6. 절제: 어떤 부품이 얼마나 기여했나
7. 실패 사례와 한계
