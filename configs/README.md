# configs/

실행 설정을 한 곳에서 관리합니다. **모델 태그, temperature, 출력 상한, 호출 예산 같은 값은 여기에만 있고, 코드는 이 파일을 읽기만 합니다.** 파이프라인마다 모델이 달라지는 사고(감점)를 막기 위한 규칙입니다. 담당 B.

키 목록과 값은 [docs/INTERFACES.md §2](../docs/INTERFACES.md)에 있습니다. 파일 형식(YAML/TOML 등)은 B가 정합니다.

## 값을 바꿀 때

- 설계안에서 온 값(상한 512/128/256, 예산 4, 재검색 2, P1 7스텝, 타임아웃 120초)을 바꾸려면 개발 세트 실험 기록(`docs/experiments/`)을 PR에 링크합니다.
- `retrieval.k`, `compress.m`은 1주차 측정 후 채웁니다.
- 측정에 쓴 설정 전체는 러너가 `RUN_META.json`에 스냅샷으로 남기므로, 측정 뒤에 설정을 바꿔도 결과를 재현할 수 있습니다.
