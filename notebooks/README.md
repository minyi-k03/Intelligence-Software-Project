# notebooks/

Colab에서 실행하는 노트북을 둡니다. 로직은 `src/`에 두고 노트북은 설치·실행·결과 확인만 합니다.

| 노트북 (제안) | 담당 | 용도 |
|---|---|---|
| `run_all.ipynb` | A | 원클릭 실행: 레포 clone → 의존성·Ollama 설치 → 모델 받기 → 해시 확인 → 묶음·라운드 실행 |
| `verify.ipynb` | A | 검증 모드: 채점자가 소수 문항만 다시 돌려 로그·점수가 재현되는지 확인 |
| `dev_*.ipynb` | 각자 | 개발 세트 실험용 (결과는 `docs/experiments/`에 기록) |

## 규칙

- 커밋 전에 출력을 지웁니다.
- 한 세션에 한 묶음만 돌립니다 (Colab 무료 버전 실행 시간 한도, ADR-0005).
- 세션이 끊기면 같은 셀을 다시 실행해 이어서 돕니다 (로그가 문항마다 저장됨).
